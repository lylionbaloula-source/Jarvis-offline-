# Jarvis Offline V2
Projet non compilé localement. GitHub télécharge le modèle Vosk lors de la compilation, pas sur le téléphone. Remplacer les fichiers à la racine du dépôt existant, supprimer Voice.kt ancien si souhaité. Le workflow doit être à la racine .github/workflows/build.yml. Si signature différente, désinstaller V1 avant installation. Autoriser micro et caméra (lampe). Installer une voix française hors ligne dans les paramètres Android si nécessaire. La voix grave est simulée par le pitch, genre non garanti. Écoute permanente expérimentale, consommation batterie possible. Les ouvertures depuis arrière-plan peuvent être bloquées par Android. Pas de modèle conversationnel, ni contrôle complet, ni SMS dans ce prototype.
